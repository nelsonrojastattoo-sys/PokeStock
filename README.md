## Estudiante

## Descripción

PokeStock es una aplicación web para la administración y venta de productos Pokémon TCG.

## Tecnologías utilizadas

- TypeScript
- Angular
- Node.js
- MongoDB (implementación futura)
- Express (implementación futura)

## Ejecución del prototipo TypeScript

```bash
cd prototipo-ts
npm install
npm run build
npm start
```

## Ejecución del proyecto Angular

```bash
cd frontend
npm install
ng serve
```
